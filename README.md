# 舒展

一个只在工作会话中运行的 macOS 健康提醒工具。它会协调远眺、轻量眨眼提醒、早中晚微运动，以及连续久坐后的起身走动提醒。主窗口关闭后，悬浮精灵和菜单栏会继续陪伴提醒。

## 当前功能

- 手动开始、暂停、继续和结束工作会话
- 默认每 20 分钟远眺 20 秒
- 每 3–7 分钟随机出现一次轻量眨眼提醒
- 连续久坐 40 分钟后提醒起身；与到期的远眺提醒自动合并
- 上午、下午、晚上工作满 30 分钟后，各提醒一次微运动
- 行动提醒可以延后 5 分钟
- 常驻悬浮精灵会显示当前状态；点击后可直接暂停、继续、确认或延后
- 完成久坐起身后自动结束并清零本轮，下次工作再手动开始
- 隐藏悬浮精灵时，后台改用 macOS 系统通知兜底
- 关闭主窗口不会退出；菜单栏可打开、切换悬浮精灵、开始/暂停/继续、结束和退出
- 菜单栏显示最近一个重要提醒（远眺或起身）的剩余时间，并与设置实时同步
- 会话检查点自动保存在本机；重启后恢复为暂停，不累计离线时间
- 工作中修改提醒间隔会立即生效，不会粗暴重置已经工作的时间
- 重复打开应用只会唤回已有窗口，不会启动多个计时实例
- 设置页可以立即测试系统通知
- 提醒间隔、启用状态保存在本机
- 每日完成次数保存在本机
- 支持浏览器预览和 Tauri 桌面应用

## 核心设计

所有计时、优先级、暂停、延后、动态设置和提醒合并规则集中在 `src/core/wellness-coordinator.ts`。界面只发送事件并呈现协调器返回的结果。核心测试使用模拟时间，不依赖真实等待或操作系统通知。

主界面、菜单栏和悬浮精灵都从同一份会话状态派生展示内容，避免三处时间和文案各自计算后出现不同步。系统通知只在悬浮精灵被隐藏时作为兜底。

## 后台使用流程

1. 打开舒展并点击“开始工作”。
2. 可以直接点击红色关闭按钮；主窗口会隐藏，悬浮精灵和菜单栏继续运行。
3. 点击精灵可展开操作卡：平时可暂停或打开主界面，提醒时可确认完成或延后。
4. 久坐提醒选择“我起来了，结束本轮”后，本轮计时归零并停止；下次工作时再点击开始。
5. 如果不想显示精灵，可从菜单栏隐藏；此时请允许系统通知，以便后台兜底提醒。
6. 点击菜单栏中的“打开舒展”或再次从 Finder/Dock 打开应用，可以恢复窗口。
7. 只有选择菜单栏中的“退出舒展”才会真正结束后台进程。
