# 舒展

一个只在工作会话中运行的桌面健康提醒工具。它会协调远眺、轻量眨眼提醒、早中晚微运动，以及连续久坐后的起身走动提醒。主窗口关闭后，应用继续在菜单栏后台运行。

## 当前功能

- 手动开始、暂停、继续和结束工作会话
- 默认每 20 分钟远眺 20 秒
- 每 3–7 分钟随机出现一次轻量眨眼提醒
- 连续久坐 40 分钟后提醒起身；与到期的远眺提醒自动合并
- 上午、下午、晚上工作满 30 分钟后，各提醒一次微运动
- 行动提醒可以延后 5 分钟
- 后台根据真实窗口焦点发送 macOS 系统通知
- 眨眼提醒在前台使用轻浮层，在后台使用安静系统通知
- 关闭主窗口不会退出；菜单栏可打开、开始/暂停/继续、结束和退出
- 菜单栏显示距离下次远眺的时间
- 会话检查点自动保存在本机；重启后恢复为暂停，不累计离线时间
- 设置页可以立即测试系统通知
- 提醒间隔、启用状态保存在本机
- 每日完成次数保存在本机
- 支持浏览器预览和 Tauri 桌面应用


## 核心设计

所有计时、优先级、暂停、延后和提醒合并规则集中在 `src/core/wellness-coordinator.ts`。界面只发送事件并呈现协调器返回的结果。核心测试使用模拟时间，不依赖真实等待或操作系统通知。

提醒呈现策略集中在 `src/notification-policy.ts`：前台和后台共享同一套内容与提醒强度规则，桌面适配器只负责把结果呈现在应用内或系统通知中。

## 后台使用流程

1. 打开舒展并点击“开始工作”。
2. 首次使用时允许系统通知。
3. 可以直接点击红色关闭按钮；窗口会隐藏，应用仍在菜单栏运行。
4. 眨眼、远眺、起身和微运动都会继续计时，并在后台通过系统通知提醒。
5. 点击菜单栏中的“打开舒展”或再次从 Finder/Dock 打开应用，可以恢复窗口。
6. 只有选择菜单栏中的“退出舒展”才会真正结束后台进程。
